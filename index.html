💡 ข้อมูลเก็บที่ไหน?
ข้อมูลเก็บอยู่ในเบราว์เซอร์ของเครื่องนี้เท่านั้น ไม่ได้ส่งขึ้นอินเทอร์เน็ต
• เปิดเครื่องอื่น หรือเบราว์เซอร์อื่น = ข้อมูลว่างเปล่า
• ล้างประวัติเบราว์เซอร์ หรือใช้โหมดไม่ระบุตัวตน = ข้อมูลอาจหาย

📦 ย้ายข้อมูลไปเครื่องอื่น (3 ขั้นตอน)
1. เครื่องเดิม: กด Backup JSON จะได้ไฟล์ ixman_backup_วันที่.json
2. ส่งไฟล์นั้นไปเครื่องใหม่ (Google Drive, LINE, อีเมล, USB)
3. เครื่องใหม่: เปิดแอป แล้วกด Restore JSON เลือกไฟล์นั้น
⚠️ Restore จะแทนที่ข้อมูลทั้งหมดในเครื่องใหม่

🛟 แนะนำ: กด Backup JSON เก็บไว้เป็นประจำ เช่น สัปดาห์ละครั้ง
Export CSV = ไฟล์สำหรับเปิดใน Excel หรือ import กลับ (ไม่มีข้อมูล master ที่แก้ไว้ครบเท่า JSON)
